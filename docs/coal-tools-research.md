# 煤炭工具研究与实现说明

调研日期：2026-10-22。逐页读取炭查查 27 个工具、5 个配煤页面以及煤价本/煤源库公开页面；以下功能描述基于调研当日页面，标准号为页面及通用方法线索，未取得全部现行国家标准正文进行认证核录。界面与实现为懂矿帝独立编写，没有引入参考站脚本。

## 入口方案

| 方案 | 优点 | 问题 | 决策 |
|---|---|---|---|
| 首页内展开所有工具 | 曝光高 | 表单繁多、配煤表格复杂，影响门户信息浏览；不利独立链接分享 | 保持首页原有布局，不新增工具版块 |
| 仅放矿123内 | 符合导航聚合定位 | 现有矿123以外站导航为主，自有工具不易发现、复访路径深 | 保持矿123原有布局，不新增工具版块 |
| 独立工具中心 | 可搜索分类、各工具独立URL、适合深度工作与扩展矿种 | 需要入口支持 | 采用；仅保留主导航“矿业工具”入口 |

已实现路径：`/tools` 工具矩阵、`/tools/calc/:id` 独立计算器、`/tools/coal` 配煤产品线、`/tools/coal/:line` 具体配煤、`/tools/records` 本机煤源库与测算历史。

实现覆盖以上 27 个工具，按通用计算、工业分析、元素分析、工艺性能、其他测定分类。输入包含单位、示例、范围校验；按计算方式切换相关字段；实时计算、公式说明、CSV 导出、本机测算保存与恢复。

关键口径：卡价单位为元/百万大卡，吨价×1000/Q；四基准以 d 为中介，灰分无 daf，Qnet 不用简单基准系数；高低位用 206×H 与 23×M 修正（J/g）；称量须质量守恒；HGI 两点只内插不外推；G<18 提示标准配比复检；罗加仅展示筛分占比，参考站自身也未提供最终 R.I. 主值。

质量扣罚支持全偏差扣罚与仅超免赔部分两种合同口径，默认按参考站的“超免赔后对全偏差扣罚”。到岸价为统一不含税费用、损耗反摊、统一税率估算，非多税目结算。

与参考站的明确差异：不编造水煤浆黏度或“可达浓度”数值，没有引入未取得的经验拟合模型；只核算设定固含量下的质量、热量平衡并标明须制浆试验。炼焦没有编造无校准的结构评分/CSR预测。电煤未加入整铲离散调度，当前为连续质量配比。未实现独立市场报价台账、云端同步、登录跨端保存；“测算记录”可保存报价计算输入与结果。输入与结果仅存本浏览器，最多100条，CSV可备份。

## 数学模型与实现

两阶段单纯形求连续线性规划，含非负约束、配比和=1、掺入上限、多指标上下限；求解后检查归一化约束残差。无解直接解释调整方向，不返回超标配方。

收到基变量 wᵢ时：干煤质量份额 dᵢ=1−Mtᵢ/100；Ad/St,d 按 wᵢdᵢ 加权，Vdaf 按 wᵢdᵢ(1−Adᵢ/100) 加权。收到基灰/硫输入先按各自全水分换成干基。FC,d=(100−Ad)×(1−Vdaf/100)。

炼焦与喷吹使用干煤质量变量 xᵢ，目标 Σ[xᵢ Pᵢ/dᵢ] 最小；收到基配比 wᵢ=(xᵢ/dᵢ)/Σ(xⱼ/dⱼ)，收到基热值/水分及掺入上限用等价线性约束变换，避免直接用湿基权重乘干煤价格造成基准偏差。采购量始终为收到基质量（水煤浆为干煤质量），成本报告同时展示湿吨与干吨。

水煤浆热值与价格直接按干煤质量口径，目标浓度 C 下每吨干煤加水(1/C−1)吨；浆体 Qnet≈C×Qnet,d−(1−C)×2300/4.1868 kcal/kg，只是理想质量和汽化热平衡，不等于可制浆性预测。

## 验证

`npm run test:coal`：89项数值与约束校验、40组独立二维顶点枚举对照（含无解与负右端约束）、隐藏字段切换、缺检测指标排除；公式数值、模式转换、单位换算、称量与百分比边界、缺输入、无解、全部五条线的配比合计/上下限/煤质约束、解析二煤配比、干湿基一致性、同粒度分桶、干煤成本反偏选案例。

`npm run build`：Vue/TypeScript 类型检查与 Vite 生产构建。浏览器人工验证：工具列表、输入实时计算、保存/恢复、配煤报告和输入变动失效、首页/矿123原布局与主导航入口、窄屏布局。
